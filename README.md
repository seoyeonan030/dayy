# 오늘은 조금 다른 하루 (A Slightly Different Day Today)

동네 곳곳을 자유롭게 걸어 다니는 **2D 횡스크롤 탐험 게임**입니다.

---

## 🎮 실행 방법
1. 바탕화면의 `오늘은_조금_다른_하루` 폴더에 들어갑니다.
2. **`index.html`** 파일을 더블 클릭하거나, **`run_game.bat`** 파일을 실행하면 웹 브라우저(Edge, Chrome 등)에서 즉시 플레이할 수 있습니다.

---

## 🕹️ 조작법
- **이동**: 키보드 `←` `→` 방향키 또는 `A` `D` 키
- **상호작용**: 오브젝트 가까이에서 `E` 키
- **친구 미니게임**: 제안에 답할 때 `GO` 입력
- **버스 미니게임**: 마우스를 움직여 장애물 피하기, `2` 키로 나가기
- **빠르게 이동**: 방향키 또는 `A`/`D`를 누른 상태에서 숫자 `1` 키를 함께 누릅니다. `1` 키를 놓으면 기본 속도로 돌아옵니다.
- **거리 이동**:
  - 화면 맨 왼쪽이나 오른쪽 끝으로 걸어가면 연결된 다음 장소로 자연스럽게 페이드 전환됩니다.
- **사운드 제어**: 키보드 `M` 키 (음소거 켜기/끄기)

---

## 🏙️ 일상의 흐름

- **집 → 집 앞 → 버스 정류장 → 버스 → 학교 → 거리 → 학원 → 집** 순서로 이동합니다.
- 집 앞, 정류장, 거리, 학교, 학원에는 짧은 대사와 함께 주변 색이 돌아오는 작은 행동이 있습니다.
- 거리에서 잠시 하늘을 바라보면 소소한 행복 엔딩으로 이어집니다.
- 학교에서 친구의 제안에 `GO`라고 답하면 평소와 다른 일상 엔딩으로 이어집니다.
- 버스가 학교 앞에 도착했을 때 내리지 않고 기다리면 마우스로 장애물을 피하는 일탈 미니게임이 시작됩니다.

엔딩 선택 메뉴 없이 게임 속 행동으로 결말이 정해집니다.
