# 오늘은 조금 다른 하루 (A Slightly Different Day Today)

동네 곳곳을 자유롭게 걸어 다니는 **2D 횡스크롤 탐험 게임**입니다.

---

## 🎮 실행 방법
1. 바탕화면의 `오늘은_조금_다른_하루` 폴더에 들어갑니다.
2. **`index.html`** 파일을 더블 클릭하거나, **`run_game.bat`** 파일을 실행하면 웹 브라우저(Edge, Chrome 등)에서 즉시 플레이할 수 있습니다.

---

## 🕹️ 조작법
- **이동**: 키보드 `←` `→` 방향키 또는 `A` `D` 키
- **상호작용**: 오브젝트 가까이에서 `스페이스` 키
- **버스 하차벨**: 하차벨 가까이에서 `K` 키
- **냉장고 퍼즐**: 마우스로 조각을 끌어 맞춥니다.
- **과제 초기화**: `X` 키
- **빠르게 이동**: 방향키 또는 `A`/`D`를 누른 상태에서 숫자 `1` 키를 함께 누릅니다. `1` 키를 놓으면 기본 속도로 돌아옵니다.
- **편의 기능**: `Tab`으로 숫자 키 안내를 켜고 끕니다. 부엌에서 `2`는 식사 전 출구 제한을 건너뛰고, `3`은 정류장에서 버스 도착·출발을 건너뛰거나 버스 안에서 학교로 이동합니다.
- **거리 이동**:
  - 화면 맨 왼쪽이나 오른쪽 끝으로 걸어가면 연결된 다음 장소로 자연스럽게 페이드 전환됩니다.
- **사운드 제어**: 키보드 `M` 키 (음소거 켜기/끄기)

---

## 🏙️ 일상의 흐름

- **내 방 → 거실과 부엌 → 엘리베이터 → 집 앞 → 버스 정류장 → 버스 안 → 학교 → 거리 → 학원 → 집** 순서로 이동합니다.
- 학교에서는 왼쪽으로 가면 거리와 학원이 차례로 나오고, 학원 왼쪽에서는 버스 정류장의 신호등 옆으로 이어집니다.
- 버스 정류장의 신호등과 상호작용하면 횡단보도를 건너 학원가로 갈 수 있습니다.
- 집 앞, 정류장, 거리, 학원에는 짧은 대사와 함께 주변 색이 돌아오는 작은 행동이 있습니다.
- 첫날에는 식탁 왼쪽 의자에서 시리얼을 먹어야 주방을 나갈 수 있습니다. 식사는 하루에 한 번만 할 수 있습니다.
- 시리얼을 먹고 학교를 다녀온 다음 날부터 냉장고 퍼즐을 이용할 수 있습니다. 퍼즐을 완성하면 식탁 오른쪽 의자에서 아침밥을 먹을 수 있습니다.
- 학교를 다녀와 집으로 돌아오면 새로운 하루가 시작되며, 엔딩 조건을 충족하지 않았다면 일상을 계속할 수 있습니다.
- 거리에서 잠시 하늘을 바라보면 소소한 행복 엔딩으로 이어집니다.
- 학교의 친구 과제가 삭제되어 평소와 다른 일상 엔딩은 현재 도달할 수 없습니다.
- 버스 정류장 의자에 앉아 3초 동안 기다린 뒤 도착한 버스를 탑니다. 버스 안에서 자리에 앉으면 운행이 시작되고, 학교에 도착했을 때 하차벨을 누른 뒤 문으로 내릴 수 있습니다.
- 버스 정차 중 하차벨을 누르지 않고 3초 동안 아무것도 하지 않으면 다시 출발합니다. 학교 전에 문으로 내리려 하면 더 가야 한다는 안내가 나옵니다.

엔딩 선택 메뉴 없이 게임 속 행동으로 결말이 정해집니다.
